# 💰 MoneyFlow

MoneyFlow is a personal finance dashboard built with React.

## Features

- Dashboard overview
- Income & expense tracking
- Balance calculation
- Transaction history
- Spending analytics (coming soon)
- Local Storage persistence
- Responsive design

## Technologies

- React
- Vite
- CSS
- Git & GitHub
